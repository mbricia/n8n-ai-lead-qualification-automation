# Portfolio & CV Copy

## Portfolio Title

AI-Powered Client Inquiry & Lead Qualification Automation

## Short Portfolio Description

Built an end-to-end n8n automation that receives client inquiries through a webhook, validates and deduplicates submissions, uses AI to extract project details, applies deterministic lead scoring, stores records in Google Sheets, generates personalized Gmail replies, and routes Hot, Warm, and Cold leads to different follow-up actions.

## Longer Case-Study Description

Designed and implemented a production-style lead intake automation for digital service businesses. The system validates incoming data, prevents duplicate submissions before LLM processing, converts free-form inquiry messages into structured fields with GPT-5 Mini, and calculates an explainable 0–100 lead score using JavaScript rules. Qualified leads are stored in Google Sheets, clients receive AI-generated personalized responses, and internal actions differ by lead quality. The workflow also includes invalid-submission logging, HTTP response handling, selective retries, and a separate failure-alert workflow.
